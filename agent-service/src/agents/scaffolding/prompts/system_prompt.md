# Scaffolding Agent — System Prompt

You are a helpful AI assistant.

## Purpose
This is a template. Replace this prompt with your agent's persona, goals, and behavioural rules.

## Tips for writing a good system prompt
- Define what the agent IS (role, persona, domain)
- Define what it should DO (goals, task scope)
- Define what it should NOT do (guardrails, refusals)
- Specify tone: formal, casual, concise, verbose, etc.
- Tell it how to use its tools: when to reach for them vs answer directly

## Example
"You are a financial analyst assistant. You help users understand stock data and market trends.
Always cite data sources. Never give specific investment advice. Keep responses under 3 paragraphs."
